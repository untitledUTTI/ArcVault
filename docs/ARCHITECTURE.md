# ArcVault · 穹档 — 产品设计与跨端架构方案（v1.0）

> **"Arc（穹）" 寓意穹顶庇护、环天顶弧光与跨越版本的连续弧线。**
> ArcVault · 穹档是一款 **Local-First（本地优先）、端到端加密（E2EE）** 的个人数字档案库与学术写作工作台，覆盖 **Windows / Android / iOS** 三端。

---

## 一、 产品定位与四大空间模型

采用 **「通用档案底座 + 场景专属工作区」** 架构：

| 空间类型 | 适用资料 | 专属核心能力 |
| :--- | :--- | :--- |
| **论文工作区（`paper`）** | `.docx`、`.tex`、`.md`、`.bib`、实验图表/数据/脚本 | 智能去封面提取 MD/LaTeX、批注修订平行卡片 + Arc-Link 光学连线、Zotero/EndNote 引文域保护、关联资产联动快照、A/B 思路分支、Rebuttal 返修草稿、一致性体检、写作热力图与进化回放 |
| **办公与文档空间（`office`）** | PDF、PPTX、XLSX、Word | 自动版本时间轴、内容摘要、内置预览、关联资料打包、规范命名一键交付 |
| **写作与知识空间（`writing`）** | Markdown、LaTeX、TXT | 大纲导航、跨版本段落/句子 Diff、片段考古全文检索、废稿墓地（Deleted Darlings） |
| **私密档案保险箱（`vault`）** | 合同、协议、证件扫描件、未发表核心稿件 | 独立密码/生物识别解锁、只读封存锁定、SHA-256/BLAKE3 完整性校验、强制本地/禁用云端 AI |

---

## 二、 核心技术选型（Tauri 2.0 跨端架构）

- **跨端宿主层**：**Tauri 2.0**（一套代码库构建 Windows 桌面端、Android、iOS，桌面后台常驻监听低内存占用）。
- **Rust 共享核心引擎（`src-tauri/`）**：
  - 内容寻址去重对象库（CAS + BLAKE3 + Zstd 压缩）
  - SQLite + FTS5 全文检索（含历史版本索引）
  - 文件夹无感后台监听（`notify` 防抖 + 定时 + 字数变化阈值）
  - 端到端加密（Argon2id 密钥派生 + XChaCha20-Poly1305）
  - 局域网 mDNS 发现 + TLS 扫码直连 & WebDAV/S3 增量同步客户端（Phase 4）
- **前端与编辑渲染层（`src/`）**：
  - **React 19 + TypeScript + Vite**
  - **CodeMirror 6** 编辑器（精准锚点装饰、双向高亮、保护态引文徽章）
  - **KaTeX** 公式实时渲染
  - **自研纯前端/跨端 OOXML 双向引擎**（`jszip` + `@xmldom/xmldom`，不依赖本机安装 Word 或 Pandoc）
  - **Phase 3 WebGL2 GLSL Shader 引擎**（「天象光影 · Celestial Optics」）

## 三、 核心机制设计

### 1. Word (`.docx`) ↔ Markdown / LaTeX 双向流转与封面剥离
1. **智能识别 + 首次可视化微调**：
   - 自动检测封面结束位置：Word 内置 Cover Page SDT → 首个分页符/分节符 → 首个 `Heading1` / `"摘要"` / `"Abstract"`。
   - 首次导入弹出可视化切分预览弹窗，用户可手动点选封面结束段落并勾选「记住此文档规则」。
   - 原始封面 XML 与媒体资源打包无损留存；回写导出 `.docx` 时自动拼回原封面并沿用原文档样式。
2. **复杂元素保真**：
   - **公式**：OMML (`m:oMath` / `m:oMathPara`) ↔ LaTeX (`$...$` / `$$...$$`) 双向转换。
   - **图片与表格**：嵌入式图片抽取至资产库并保持引用；表格与多级标题结构保留并映射原样式。
   - **脚注/尾注/交叉引用**：抽取为标准化语义标记并保留书签映射。
   - **Zotero / EndNote 引文域保护**：扫描 `w:fldChar` / `w:instrText`，将原始 XML 存入 `citationsSidecar`，正文显示为受保护占位符 `[@zotero:001]` / `[@endnote:001]`，回写 Word 时原样注回域代码。
3. **格式自选**：每个文档/项目可选择生成 Markdown、LaTeX 或双格式同步维护。

### 2. 批注 & 修订平行侧栏卡片 + Arc-Link 双向高亮 + 统一撤销重做
- **保留原文**：Word 中的批注（`comments.xml`）与修订（`w:ins` / `w:del`）在提取为 MD/LaTeX 时**保留原文内容**写入正文，修改建议与批注信息结构化存入侧栏锚点列表。
- **平行对齐与防重叠**：根据编辑器内锚点实时屏幕 Y 坐标动态对齐右侧卡片，多条同段批注自动防重叠排布。
- **Arc-Link 光学连线与双向悬浮高亮**：鼠标悬浮原文高亮区或侧栏卡片时，同时强高亮原文与卡片，并在锚点与卡片之间绘制平滑发光 Bezier 光学弧线（批注默认蓝 `#2563eb`，修订默认红 `#dc2626`，均可在设置中自定义）。
- **卡片交互**：支持「接受修订」「拒绝修订」「标记已解决 / 回复」「AI 修改建议」。
- **全局 & 编辑器级 Undo / Redo**：统一命令栈事务（`CommandHistory`），同时维护文本快照与所有批注/修订锚点偏移量，支持任意组合编辑与卡片操作后的多步 `Ctrl+Z` / `Ctrl+Y`。

### 3. 省钱且方便的三端同步协议（Phase 4 落地，数据模型已就绪）
- **通道 1（局域网高速直连）**：同一 Wi-Fi 下 mDNS 自动发现 + 二维码扫码 TLS 双向配对，零流量满速增量同步。
- **通道 2（免费/低成本云盘兜底）**：WebDAV（坚果云 / Alist / NAS）与 S3 兼容对象存储（Cloudflare R2 免费 10GB / 阿里云 OSS）。全部内容块离端前均经本地 E2EE 加密，云端不可读。
- **离线优先（Local-First）**：三端断网可用，基于逻辑时钟（HLC）`sync_oplog` 增量同步，并发冲突弹出可视化对比合并界面。

### 4. 双轨视觉系统
- **默认模式（现代极简工作台）**：内置 **浅色（Light）**、**深色（Dark）**、**护眼纸感（Paper）**、**Material 3 Expressive** 四套主题，中/英实时切换。
- **可选高性能模式「天象光影 · Celestial Optics」（Phase 3）**：基于 WebGL2 自定义 Shader 实现 **维纳斯带**、**曙暮光条**、**钻石尘粒子**、**幻日色散微晕** 与 **星空星座版本图谱**，支持三档性能调节与毛玻璃可读性护航。
